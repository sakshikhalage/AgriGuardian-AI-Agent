\# 🌾 AgriGuardian AI Agent



AgriGuardian AI Agent is an AI-powered farming assistant designed to help farmers make better decisions about crops, weather, irrigation, pests, diseases, and agricultural markets.



\## 🚀 Features



\- 🌦️ Weather Information

\- 🌱 AI Crop Recommendation

\- 🐛 Pest \& Disease Guidance

\- 💧 Irrigation Guidance

\- 📊 Market Price Comparison

\- 💰 Net Return Calculator

\- 🏪 Smart Market Recommendation

\- 🤖 AI Farming Assistant

\- 🔐 User Signup and Login

\- 🌐 Support for multiple languages



\## 🧠 AI



AgriGuardian uses Google's Gemini AI to provide farming guidance and recommendations.



\## 🛠️ Technology Stack



\### Backend

\- Python

\- FastAPI

\- SQLite

\- Google Gemini API

\- Requests

\- Argon2 password hashing



\### Frontend

\- JavaScript
